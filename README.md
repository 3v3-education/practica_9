# Red Social Django

Proyecto base de un blog web desarrollado con Django.

## Descripción

Este repositorio contiene la estructura inicial de un proyecto Django para construir una red social.  Incluye la configuración base del proyecto y una aplicación llamada `publicaciones`.

## Instalación

Clonar el repositorio:
```bashgit clone URL_DEL_REPOSITORIO```
Entrar a la carpeta del proyecto:```cd NOMBRE_DEL_REPOSITORIO```
Crear entorno virtual:python -m venv venv
Activar entorno virtual:En Windows PowerShell:```.\venv\Scripts\Activate.ps1```

En Linux o macOS:```source venv/bin/activate```
Instalar dependencias:```pip install -r requirements.txt```
Ejecutar el servidor:```python manage.py runserver```

Abrir en el navegador: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

Aplicaciones- publicaciones: aplicación inicial para manejar las publicaciones de la red social.
